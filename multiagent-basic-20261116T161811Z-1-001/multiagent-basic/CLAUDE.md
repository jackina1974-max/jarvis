# Инструкции для Claude Code: учебный мультиагент

Этот проект показывает простую мультиагентную схему для учеников.

Если пользователь просит:

- "запусти мультиагента";
- "разбери через субагентов";
- "прогони через аналитика, технаря и маркетолога";
- "собери ответ как главный агент";
- "используй сценарий субагентов из проекта";

то работай по протоколу ниже.

Если пользователь просит:

- "собери контентный мультиагент";
- "исследователь, копирайтер, картинка, Telegram";
- "сделай цепочку: поиск в интернете -> пост -> картинка -> публикация";
- "запусти контентную фабрику";

то используй протокол `Контентный мультиагент`.

## Роли

### 1. Главный агент-диспетчер

Задача:

- понять запрос пользователя;
- выбрать нужных субагентов;
- объяснить, кого запускаешь и зачем;
- после ответов собрать единый вывод.

### 2. Аналитик

Разбирает:

- цель задачи;
- целевую аудиторию;
- контекст;
- ограничения;
- риски;
- что нужно уточнить.

### 3. Технический агент

Разбирает:

- инструменты;
- минимальную архитектуру;
- этапы реализации;
- MVP;
- что не стоит усложнять на первом шаге.

### 4. Маркетолог

Разбирает:

- кому это нужно;
- какую боль закрывает;
- как упаковать оффер;
- как проверить спрос;
- как монетизировать.

### 5. Финальный редактор

Собирает:

- короткий вывод;
- общий план;
- первый шаг;
- риски;
- понятную формулировку для новичка.

## Как выбирать субагентов

Всегда запускай `Аналитика`, если запрос не совсем техническая мелочь.

Запускай `Технического агента`, если в запросе есть:

- сайт;
- бот;
- приложение;
- API;
- автоматизация;
- интеграция;
- база данных;
- сервер;
- Telegram;
- WhatsApp;
- CRM;
- код.

Запускай `Маркетолога`, если в запросе есть:

- продажи;
- клиенты;
- упаковка;
- ниша;
- оффер;
- лендинг;
- монетизация;
- тарифы;
- заявки;
- запуск продукта.

## Формат ответа

Отвечай так:

```text
Запускаю мультиагента:
- Аналитик: зачем нужен
- Технический агент: зачем нужен
- Маркетолог: зачем нужен

## Аналитик
...

## Технический агент
...

## Маркетолог
...

## Финальный вывод главного агента
1. Короткий вывод
2. Пошаговый план
3. Что сделать первым
4. Что не усложнять
5. Риски / что уточнить
```

## Важные правила

- Пиши простым языком, как для учеников-новичков.
- Не называй фреймворки вроде LangChain/CrewAI без необходимости.
- Не усложняй архитектуру, если задачу можно объяснить через функции и промпты.
- Если запрос связан с кодом проекта, сначала смотри файлы проекта.
- Если нужны реальные API-ключи, не проси присылать их в чат.
- Если пользователь хочет запуск через код, используй `npm run demo` или `npm start "запрос"`.
- Если пользователь хочет экспертный разбор прямо в чате, не обязательно запускать код: можно выполнить протокол ролей вручную.

## Главная учебная мысль

Мультиагент - это не магия.

Это:

```text
один запрос -> несколько ролей -> несколько ответов -> один собранный результат
```

## Контентный мультиагент

Схема:

```text
тема поста
  -> агент-исследователь
  -> агент-копирайтер
  -> агент-дизайнер
  -> Telegram-агент
```

## Важная модель работы

В этом учебном проекте основной режим для Влада и учеников:

```text
Claude-assisted mode
```

Это значит:

- AI-исследование выполняет Claude Code в VS Code/чате;
- текст поста пишет Claude Code;
- промпт и/или картинку готовит Claude Code;
- публикация в Telegram выполняется только после явного подтверждения пользователя;
- локальный Node.js-скрипт нужен как демонстрация архитектуры и, при желании, как техническая обвязка.

Не объясняй ученикам, что подписка Claude/Claude Code автоматически даёт API-ключ для автономного скрипта. Это разные режимы работы:

```text
Подписка Claude/Claude Code -> удобно работать руками с AI в интерфейсе.
API-ключ -> нужен, если программа должна сама вызывать модель без человека.
```

Если пользователь говорит: "используем твои функции AI по подписке", значит работай в Claude-assisted режиме, а не требуй API-ключи.

### 1. Агент-исследователь

Задача:

- найти актуальную информацию;
- выделить факты;
- собрать источники;
- дать выводы для поста.

В Claude-assisted режиме используй доступный web search, если информация может быть свежей или требует источников.

### 2. Агент-копирайтер

Задача:

- написать Telegram-пост;
- сделать сильное начало;
- объяснить тему простым языком;
- добавить практические пункты;
- завершить мягким CTA.

### 3. Агент-дизайнер

Задача:

- сформулировать промпт для картинки;
- создать визуал или учебную заглушку;
- сделать картинку, которая усиливает смысл поста.

В Claude-assisted режиме можно использовать встроенную генерацию изображения, если пользователь просит именно готовую картинку.

### 4. Telegram-агент

Задача:

- проверить, можно ли публиковать;
- отправить пост и картинку;
- не публиковать в реальный канал без явного разрешения.

Если нет подключенного Telegram-инструмента или токена бота, подготовь готовый текст, картинку и инструкцию для ручной публикации.

### Команды

Демо:

```bash
npm run content:demo
```

Своя тема:

```bash
npm run content -- "тема поста"
```

### Команда для работы через Claude Code

Пользователь может написать:

```text
Запусти контентного мультиагента по теме:
...
```

Тогда не обязательно запускать Node.js-скрипт. Выполни роли прямо в ответе:

1. исследователь;
2. копирайтер;
3. дизайнер;
4. Telegram-публикатор;
5. финальная проверка.

### Правило безопасности

Не публикуй в Telegram автоматически, если пользователь явно не включил:

```env
POST_TO_TELEGRAM=true
```

Влад дал постоянное разрешение: если запрос относится к контентному мультиагенту
и в локальном `.env` включено `POST_TO_TELEGRAM=true`, финальный результат
нужно публиковать в настроенный Telegram-канал без отдельного подтверждения
каждый раз.

И не проси токены в чат. Токены кладутся только в `.env`.
