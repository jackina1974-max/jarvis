# Контентный мультиагент через Claude Code

Этот сценарий нужен, если AI-функции выполняет Claude Code по подписке, а не отдельный API-ключ.

## Как пользоваться

Откройте проект `multiagent-basic` в VS Code и напишите Claude Code:

```text
Запусти контентного мультиагента по теме:
5 ошибок малого бизнеса при внедрении ИИ

Нужно:
1. найти информацию в интернете;
2. написать Telegram-пост;
3. подготовить промпт для картинки;
4. сгенерировать картинку;
5. подготовить публикацию для Telegram.
```

## Что должен сделать Claude Code

### 1. Исследователь

- найти свежую информацию;
- выделить факты;
- дать ссылки на источники;
- сформулировать главную мысль поста.

### 2. Копирайтер

- написать Telegram-пост;
- сделать сильное начало;
- дать практические пункты;
- завершить мягким CTA.

### 3. Дизайнер

- придумать визуальную идею;
- подготовить промпт;
- сгенерировать картинку или сохранить промпт для генерации.

### 4. Telegram-публикатор

- подготовить финальный текст;
- проверить длину подписи;
- если нет токена/инструмента публикации, дать инструкцию для ручной публикации;
- если токен есть и пользователь явно разрешил, можно публиковать через Telegram Bot API.

## Безопасность

Не публиковать автоматически без явного подтверждения.

Не просить токены в чат.

Не вставлять API-ключи в код.

Не выдавать непроверенные факты без источников, если пост зависит от свежей информации.
